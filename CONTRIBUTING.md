# Contributing

This repository is a **personal take-home / internship project, published so reviewers can follow my progress**.

- It is **read-only for observers**. You do not need to clone, install, or run anything to review it.
- I am **not accepting pull requests or feature requests**. Unsolicited PRs will be closed without review.
- Issues are disabled. If you are a reviewer and want to tell me something, contact me directly (see the README).
- Forking is allowed by GitHub, but no license is granted for reuse (see the README).

## For me (the owner)
- Work on `feat/<name>` branches, open a PR into `main`, wait for the `CI passed` check.
- Commit style: `feat: ...`, `fix: ...`, `docs: ...`, `chore: ...`, `test: ...`.
- Never commit `.env` files. Only `*.example` files.

## Security
If you notice an exposed secret or vulnerability, please contact me directly instead of opening a public issue.
